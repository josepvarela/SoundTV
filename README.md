# 📺 SoundTV App para Samsung Tizen

Una aplicación no oficial de Twitch optimizada para **Smart TVs Samsung (Tizen OS)**, con una interfaz oscura diseñada para navegar cómodamente con el control remoto.

> ⚠️ **Aviso:** Este proyecto no está afiliado ni respaldado por Twitch Interactive, Inc.

---

## ✨ Características

- 🎮 Interfaz oscura optimizada para control remoto.
- 📂 Navegación lateral (Sidebar) para streams seguidos, juegos y canales.
- 🖼️ Cuadrícula de streams en vivo con miniaturas y espectadores.
- ▶️ Reproductor de video integrado (HLS).
- 💬 Visor de chat en vivo *(próximamente)*.
- 🔐 Credenciales protegidas mediante variables de entorno en Vercel.

---

## 🛠️ Tecnologías utilizadas

- **HTML5 / CSS3 / JavaScript (Vanilla)**
- **Tizen Web App** (Samsung TV)
- **Twitch API (Helix)**
- **Vercel** (Despliegue y variables de entorno)
- **HLS.js** (Reproducción de streams)
